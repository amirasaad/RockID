# Friends Beta Wave 1 Release Note

Date: May 8, 2026  
Build: v0.30.0 (or your shared beta build identifier)

## What This Beta Is
Rock ID Friends Beta Wave 1 is an offline-first test focused on real user flow quality:
- capture/upload photo
- identify with confidence messaging
- save/reopen/reanalyze
- report quality and usability feedback

## What We Need Testers To Do
- Complete missions in `docs/beta/Test-Missions.md`
- Submit feedback only via GitHub Issue Templates:
  - Wrong Result Report
  - Bug / Crash Report
  - UX Friction Report

## Known Limits (Expected)
- No cloud sync/account flow in this wave
- Confidence may be uncertain on ambiguous samples
- Non-rock confusers may still appear in alternatives

## What Changed For This Wave
- Structured GitHub beta issue intake
- Tester onboarding docs and triage runbook
- Wave acceptance criteria and daily triage contract

## How We’ll Triage
- Every issue gets category + priority labels
- High-priority beta issues are fixed in-wave or explicitly deferred
- Weekly changelog update posted for retest guidance

## Success Criteria
- 10+ completed tester reports
- 100% triage within 24h
- High-priority issues resolved or clearly deferred
- End-of-wave summary with next sprint decisions
