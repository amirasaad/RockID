## **Update Rules**

- Update [../Kanban.md](<../Kanban.md>) when work moves between backlog, ready, in progress, review, and done.
- Update the relevant sprint file when a story changes status or DoD evidence changes.
- Update [EpicMilestones.md](<EpicMilestones.md>) when an epic milestone changes status.
- Keep links relative inside docs.
